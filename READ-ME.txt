HydrogenI BoxTwin 3D — MVP Completo
Aplicação Flask para demonstração e operação da medição automatizada do volume de fertilizantes em boxes. O sistema integra um gêmeo digital 3D, gestão de anomalias, notificações inteligentes, assistente técnico com RAG e suporte para sensor físico VL53L8CX, com total rastreabilidade e funcionamento offline.

🚀 O que este MVP inclui
✅ 9 cenários de demonstração (vazio, 25%, 50%, 75%, quase cheio, pilha central, inclinação, irregular e obstrução)

✅ Calibração do box vazio e cálculo preciso de volume, ocupação, altura média e máxima

✅ Matriz de profundidade 8×8 com 64 zonas de leitura

✅ Gêmeo digital 3D renderizado em Canvas (sem bibliotecas externas)

✅ Histórico local em SQLite e gráfico de evolução da ocupação

✅ Alertas de capacidade, confiança e obstrução

✅ Painel administrativo com autenticação (/admin)

✅ Fila de anomalias com status: aberta, ciente, em atendimento, resolvida e falso positivo

✅ Atualização em tempo real via Server-Sent Events (SSE)

✅ Notificações opcionais por SMTP (e-mail) e Twilio (SMS/WhatsApp) com escalonamento

✅ Assistente técnico com RAG local (procedimentos) e fallback para Grok (xAI)

✅ Cadastro de responsáveis e regras de notificação por tipo/severidade

✅ Relatório operacional em PDF com indicadores, leituras e incidentes

✅ PWA (Progressive Web App) responsiva para dispositivos móveis

✅ Suporte a HTTPS (SSL) com geração automática de certificados autoassinados

✅ Fila offline para notificações – retry automático em caso de falha de rede

✅ Script de configuração de rede corporativa (IP fixo e WPA2-Enterprise)

🔌 Integração com o Sensor VL53L8CX
O ponto de integração está em boxtwin/sensors/vl53l8cx.py. O adaptador deve retornar uma lista 8×8 em milímetros, com None para zonas inválidas.

Assim que o hardware chegar, instale o driver apropriado e implemente o método read_distance_grid_mm(). Depois, basta alterar no .env:

dotenv
SENSOR_MODE=vl53l8cx
Todo o restante do sistema (cálculo, banco, API, alertas e painel) não precisará ser reescrito.

🔒 SSL / HTTPS (Certificado Autoassinado)
Para ativar HTTPS em desenvolvimento ou redes locais:

Defina no .env:

dotenv
SSL_CERT_PATH=cert.pem
SSL_KEY_PATH=key.pem
SSL_AUTO_GENERATE=True
Execute o comando para gerar o certificado (caso não gere automaticamente):

bash
python -c "from boxtwin.security import SSLManager; SSLManager(cert_path='cert.pem', key_path='key.pem', auto_generate=True)"
Reinicie a aplicação. O servidor passará a servir HTTPS na porta configurada.

📶 Configuração de Rede Corporativa
Execute o script interativo para configurar IP fixo ou Wi-Fi WPA2-Enterprise no Raspberry Pi:

bash
sudo ./boxtwin/network_setup.sh
O script permite:

Definir um IP estático via dhcpcd

Configurar redes Wi-Fi corporativas com autenticação EAP/PEAP/MSCHAPv2

Reinicie o sistema para aplicar as mudanças.

📦 Fila Offline de Notificações
Quando uma notificação (e-mail ou SMS) falha, o sistema a enfileira e tenta reenviar automaticamente nos ciclos seguintes, até o limite de tentativas definido em OFFLINE_MAX_ATTEMPTS (padrão: 5).

O arquivo da fila fica em data/offline_queue.json.

O processamento ocorre a cada intervalo de captura (SAMPLE_INTERVAL_SECONDS).

🤖 Assistente Técnico (RAG + Grok)
O assistente utiliza uma base de conhecimento local em boxtwin/knowledge/procedures.json. Ao fazer uma pergunta, ele:

Recupera os procedimentos mais relevantes por similaridade de tokens.

Gera uma tratativa rastreável citando as fontes.

Se XAI_ENABLED=True e a chave da xAI estiver configurada, utiliza o modelo Grok para enriquecer a resposta, com fallback automático para o RAG local.

O contexto da pergunta é automaticamente enriquecido com a última leitura e anomalias ativas.

⚠️ Limites desta versão
Os números no modo mock demonstram o método matemático e a experiência operacional, mas não constituem validação de precisão do sensor real. A margem de erro industrial deverá ser medida após a instalação do VL53L8CX com volumes físicos conhecidos.

🚀 Deploy em Produção (Raspberry Pi)
Crie um serviço systemd para iniciar automaticamente:

bash
sudo nano /etc/systemd/system/boxtwin.service
ini
[Unit]
Description=HydrogenI BoxTwin
After=network.target

[Service]
User=pi
WorkingDirectory=/home/pi/HydrogenI-BoxTwin
ExecStart=/home/pi/HydrogenI-BoxTwin/.venv/bin/gunicorn --bind 0.0.0.0:5000 --workers 1 --threads 8 --timeout 120 app:app
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
Ative e inicie:

bash
sudo systemctl enable boxtwin.service
sudo systemctl start boxtwin.service
